## v8：固まる／真っ白になる原因（本命）

送っていただいた「背景色だけの真っ白な画面」は、JavaScriptのエラー画面ではなく
**Safariの描画プロセスが強制終了された状態**です（PWAの background_color だけが残る）。
記録用に仕込んだ赤いエラー枠も出ていないので、JavaScriptの例外ではありません。

原因として最も可能性が高いのは **コマの影の描き方** でした。

```css
.disc svg { filter: drop-shadow(0 2px 1px rgba(0,0,0,.2)); }
```

コマ1つに SVG が表裏2枚入っているため、盤が埋まると
**最大128枚ぶんのGPUフィルタ処理**が同時にかかります。
`filter` は1つごとにオフスクリーンのバッファを確保するため、
描画メモリを一気に消費します。しかも**コマが増えるほど重くなる**ので、
「終盤で落ちる」という症状と完全に一致します。

対策：`filter` を全廃し、影を **SVGの中の円** として描くように変更しました
（見た目はほぼ同じ、GPU負荷はゼロ）。ダンジョンの鍵つきアイコンの
`brightness()` / `grayscale()` も同様に削除しています。

**読み上げも既定オフに変更しました。** iOSの `speechSynthesis` は
連続呼び出しで描画プロセスが落ちる事例が知られているため、
まず容疑者を外した状態で確認していただくためです。
🔊ボタンでいつでもオンにできます（設定は端末に保存されます）。

### 切り分けのお願い
v8 で様子を見て、次のどちらかを教えてください。

- **直った** → 原因は上記のGPU負荷で確定です。
- **まだ固まる** → 読み上げをオン（🔊）にしたときだけ固まるかを見てください。
  オンのときだけなら speechSynthesis、常に固まるなら次の手として
  コマの3D反転（`transform-style: preserve-3d`。これも1コマ2枚ぶんの
  合成レイヤを作ります）を、レイヤを使わない横スケール反転に
  置き換える改修を行います。

## v7 で直したこと

### アイコンが表示されない（原因確定）
`index.html` / `manifest.webmanifest` / `sw.js` がすべて `icons/icon-192.png` を
参照していたのに対し、実ファイルはリポジトリ直下にあり全部404でした。
さらに Service Worker の `cache.addAll()` は**1ファイルでも404だと全体が失敗する**
仕様のため、SWのインストール自体が毎回コケていました（オフライン動作も無効）。

- 参照パスをルート直下（`./icon-192.png`）に統一
- `apple-touch-icon` に 180x180 の明示指定を追加
- manifest の `purpose` を `any` と `maskable` に分離
- SWのキャッシュ登録を1ファイルずつに変更（1つ欠けても他は残る）

### 終盤の負荷対策
- 効果音：同時発音を6個までに制限し、鳴り終わったノードを必ず `disconnect`。
  めくり音は先頭5枚のみ、アニメ遅延は480msで頭打ち
- 読み上げ：1.1秒の間隔制限・60文字で打ち切り・バックグラウンド時に `cancel`
- 最後の一手のめくりアニメが消える不具合を修正

### 原因追跡
JavaScriptの例外が起きた場合、内容を端末に記録し
**メニュー画面下部の赤い枠**に表示します（タップで消去）。
